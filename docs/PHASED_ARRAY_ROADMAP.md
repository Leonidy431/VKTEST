# Phased Array Robotics — Roadmap 3 Phases

**Статус:** Phase 1 MVP (в разработке)  
**Дата начала:** 2026-07-08  
**Цель:** От готовых модулей к полностью кастомной AESA системе

---

## Phase 1: MVP (Минимальный жизнеспособный продукт)

**Длительность:** 3 недели  
**Тип:** Ready-to-integrate (готовые компоненты)  
**Стоимость:** ~$545 BOM  
**Сложность:** ⭐ Низкая (интегратор)

### Цель фазы
Создать рабочую систему связи `robot ↔ phone` на готовых RF модулях
с адаптивным управлением мощностью, голосовой связью и формированием луча.

### Две подсистемы MVP

#### A. RF Management (данные, управление)
- RF чипсет (Qorvo/Wi-Fi7), инициализация, TX/RX
- Адаптивная мощность (по RSSI)
- Логирование метрик

#### B. Audio Streaming (голос, звонки) ⭐ NEW
- Захват/передача аудио (микрофон → Wi-Fi)
- Адаптивные кодеки (Opus, GSM AMR)
- Контроль качества (MOS score, latency)
- Интеграция с RF (автоматическая смена кодека по RSSI)

### Этапы

#### Этап 1.1: Закупка компонентов (неделя 1)
- ✓ Qorvo QPM56xx evaluation board или Wi-Fi 7 роутер
- ✓ LMR-100 RF кабели, IPEX/SMA разъемы
- ✓ Xilinx Zynq-7010 FPGA плата (для управления питанием)
- ✓ Алюминиевые крепежи, монтажные материалы
- **Критерий приемки:** Все компоненты получены, проведена визуальная инспекция

#### Этап 1.2: Механический монтаж (неделя 1-2)
- ✓ Демонтировать встроенные антенны
- ✓ Припаять кабели на разъемы (IPEX/SMA)
- ✓ Смонтировать на корпусе робота (кронштейны из алюминия)
- ✓ Проверить механическую жесткость (тряска, вибрация)
- **Критерий приемки:** Антенны зафиксированы, кабели не натянуты

#### Этап 1.3: Программное обеспечение управления (неделя 2-3)
- ✓ Python API для инициализации RF чипсета (SPI/I2C)
- ✓ Контроль питания PA через FPGA GPIO
- ✓ Чтение RSSI и метрик в реальном времени
- ✓ Интеграция с mainloop робота (state_machine.py)
- ✓ **NEW:** AudioStreamer — захват/передача голоса с адаптивными кодеками
- ✓ **NEW:** Адаптивный выбор кодека (Opus, GSM AMR) по RSSI
- ✓ **NEW:** Расчет MOS score и контроль качества голоса
- **Критерий приемки:** RF инициализируется, RSSI читается, TX мощность регулируется, аудио кодируется и готово к передаче

#### Этап 1.4: Базовое тестирование (неделя 3)
- ✓ Проверка связи на расстояниях 10, 25, 50 м
- ✓ Измерение диаграммы направленности вручную (поворот робота)
- ✓ Проверка стабильности (нет разрывов связи)
- ✓ Тепловой тест (30 минут непрерывной TX)
- ✓ **NEW:** Тест голосовой связи — разборчивость на разных RSSI
- ✓ **NEW:** Проверка адаптации кодека (Opus → GSM AMR при падении RSSI)
- ✓ **NEW:** Измерение задержки (latency) и потери пакетов
- **Критерий приемки:** Связь стабильна, голос разборчив на дальности 50 м, температура < 95°C

### Результат Phase 1
```
Рабочий прототип "базовой станции" на роботе с голосовой связью
├── Qorvo/Wi-Fi7 модуль (RF тракт)
├── Python API (управление SPI/I2C)
├── AudioStreamer (захват и передача голоса)
├── Адаптивные кодеки (Opus, GSM AMR по RSSI)
├── Контроль качества (MOS score, latency)
├── Логирование метрик (RSSI, T, P, MOS, jitter)
└── Интеграция с control/state_machine.py
```

### Deliverables
- 📁 `phased_array/` модуль с 5 подмодулями:
  - config.py
  - rf_module.py
  - beamforming.py
  - power_manager.py
  - **audio_streamer.py** ⭐ NEW
- 📋 README с инструкциями (английский + русский)
- 🧪 25+ тестов (pytest, покрытие >80%):
  - 21 RF тест
  - 20 beamforming тест
  - **12 audio тестов** ⭐ NEW
- 📊 Диаграмма направленности (паттерны в зависимости от азимута)
- 📝 Лог метрик за 24 часа работы
- 📖 **AUDIO_STREAMING_SPECIFICATION.md** ⭐ NEW (спецификация голосовой связи)

## Phase 2: Optimization & Validation

**Длительность:** 3 недели (неделя 4-6)  
**Тип:** Fine-tuning (оптимизация)  
**Стоимость:** ~$0 (повторное использование компонентов)  
**Сложность:** ⭐⭐ Средняя (инженер RF)

### Цель фазы
Оптимизировать RF производительность и подготовиться к полной разработке.

### Этапы

#### Этап 2.1: Цифровое управление фазой (встроенное)
- ✓ Изучить datasheet Qorvo/Wi-Fi7 для поддержки phase shifters
- ✓ Реализовать SPI команды к фазовращателям (если есть в чипсете)
- ✓ Алгоритм калибровки фазовых сдвигов
- ✓ Тестирование фазового управления в анихотической камере
- **Критерий приемки:** Фазовые сдвиги ±180° с точностью ±5°

#### Этап 2.2: Алгоритм сканирования луча (beam scanning)
- ✓ Реализовать `scan_beam_pattern()` для поиска максимума
- ✓ Адаптивный выбор направления луча по RSSI
- ✓ Кэширование паттернов для ускорения
- **Критерий приемки:** Сканирование 0-360° за <2 секунды

#### Этап 2.3: Тестирование в реальной среде
- ✓ Измерение дальности в помещении (многолучевое распространение)
- ✓ Измерение в открытом пространстве (LoS — line of sight)
- ✓ Проверка помехоустойчивости (соседние Wi-Fi сети)
- ✓ Тестирование на подвижных объектах (робот движется)
- **Критерий приемки:** Дальность ≥80 м в открытом пространстве

#### Этап 2.4: Документирование и валидация
- ✓ Технический отчет с измерениями RF параметров
- ✓ Таблица зависимости RSSI от расстояния (калибровочная кривая)
- ✓ Диаграммы направленности (gain vs. azimuth в полярных координатах)
- ✓ Рекомендации по монтажу (высота антенны, экранирование)
- **Критерий приемки:** Документация на 20+ страниц с графиками

### Результат Phase 2
```
Оптимизированная система с известными RF характеристиками
├── Встроенное управление фазой (если поддерживается)
├── Адаптивный scan_beam_pattern()
├── Калибровочные данные (дальность vs. RSSI)
└── Полная RF документация
```

### Deliverables
- 📊 RF Datasheet (параметры, диаграммы, таблицы)
- 📈 Кривая "Дальность vs. RSSI" (построена экспериментально)
- 🎯 Полярные диаграммы направленности (15+ паттернов)
- 🔬 Отчет тестирования в полевых условиях
- ✅ Чек-лист монтажа и настройки для производства

## Phase 3: Full Custom AESA Design

**Длительность:** 6 недель (неделя 7-12)  
**Тип:** Custom engineering (собственная разработка)  
**Стоимость:** $2000-5000 (прототипирование + производство)  
**Сложность:** ⭐⭐⭐ Высокая (RF + FPGA инженер)

### Цель фазы
Создать собственную ФАР плату с полным цифровым контролем фазы
и адаптивным формированием луча.

### Этапы

#### Этап 3.1: Проектирование схемы KiCad
- ✓ Выбор компонентов (phase shifters, PA/LNA, биас цепи)
  - Phase Shifters: Analog Devices HMC6300 (6-бит, SPI)
  - PA: Qorvo QPA3005 (+25 дБм, 5-6 ГГц)
  - LNA: Analog Devices ADL5543 (20 dB gain, 2.5 dB NF)
- ✓ Согласование импеданса (matching networks 50 Ом)
- ✓ Развязка цифровых и аналоговых цепей (ферритовые бусины)
- ✓ Схема питания (48V → 12V → 5V/3.3V с LC фильтрацией)
- **Критерий приемки:** Netlist готов для импорта в KiCad, все компоненты на складе

#### Этап 3.2: Разводка платы (4 слойная PCB)
- ✓ Выбор ламината (Rogers 4003C для ВЧ слоев)
- ✓ Стек слоев: Signal-GND-Signal-GND (контролируемый импеданс)
- ✓ Трассировка 50 Ом микрополосковых линий (width расчет)
- ✓ Расположение элементов (фазовращатели близко к PA)
- ✓ RF разделение и экранирование
- **Критерий приемки:** Design Rule Check (DRC) пройден, файлы готовы к производству

#### Этап 3.3: Изготовление и сборка прототипа
- ✓ Заказ прототипа платы (6-8 недель)
- ✓ Закупка компонентов (lead time контроль)
- ✓ Ручная сборка / микроэлектроника
- ✓ Припой рефлоу для BGA компонентов
- ✓ Визуальная инспекция под микроскопом
- **Критерий приемки:** Плата собрана, нет видимых дефектов, continuity проверена

#### Этап 3.4: FPGA управление
- ✓ Xilinx Vivado проект (Zynq-7010)
- ✓ SPI контроллер к phase shifters (HMC6300)
- ✓ ADC/DAC интерфейс для IQ модуляции
- ✓ UART для отладки и логирования
- ✓ Реализация DBF (Digital Beamforming) алгоритма
- **Критерий приемки:** FPGA bootует, SPI команды работают, фазовращатели отзываются

#### Этап 3.5: Алгоритм цифрового формирования луча (DBF)
- ✓ Реализация на FPGA: матрица весов (16 элементов)
- ✓ Real-time обработка фазовых сдвигов (100+ лучей/сек)
- ✓ Адаптивное формирование луча (ACS — Adaptive Coordinate Selection)
- ✓ Компенсация многолучевого распространения (multipath mitigation)
- **Критерий приемки:** Луч качается в реальном времени, задержка <10 мс

#### Этап 3.6: Полевое тестирование и сертификация
- ✓ Диаграмма направленности в анихотической камере (±45° по азимуту)
- ✓ Измерение S-параметров (VNA — Vector Network Analyzer)
- ✓ Спектральное загрязнение (спектроанализатор, ±100 МГц)
- ✓ EMC тестирование (по ГОСТу 30108-94 / CE директиве)
- ✓ Тестирование на помехоустойчивость (IEC 61000-4-3)
- **Критерий приемки:** Сертификационный отчет получен

### Результат Phase 3
```
Полностью кастомная AESA система (16 элементов)
├── KiCad проект (схема + топология PCB)
├── FPGA firmware (Vivado, DBF алгоритм)
├── Собственная ФАР плата (Rogers 4×4 мм, 4 слоя)
├── Phase shifters (SPI управление)
├── Диаграммы направленности (измеренные + симулированные)
├── EMC/RF сертификация
└── Производственная документация
```

### Deliverables
- 📐 KiCad проект (.kicad_sch, .kicad_pcb, Gerber)
- 📁 FPGA firmware (Vivado project, Verilog/VHDL, bitstream)
- 📊 S-параметры (S11, S21, S12, S22 для всех компонентов)
- 📈 Измеренные диаграммы направленности (полярные графики)
- 📋 EMC сертификационный отчет
- 🔍 BOM с производственными допусками
- 📖 Руководство по сборке и настройке

## Критерии успеха проекта

### Phase 1 ✓ COMPLETE
- [ ] Модуль инициализируется без ошибок
- [ ] RSSI логируется корректно (-20…-100 дБм)
- [ ] TX мощность регулируется в диапазоне ±6 дБм
- [ ] Видеопоток 720p@30fps работает стабильно
- [ ] Нет разрывов связи при движении робота
- [ ] PA температура <95°C при 30 мин TX

### Phase 2 ✓ OPTIMIZE
- [ ] Дальность достигает 80+ метров в open space
- [ ] Сканирование луча работает за <2 сек
- [ ] RSSI улучшается на 3+ дБ при адаптивном луче
- [ ] Помехоустойчивость к соседним Wi-Fi сетям
- [ ] Калибровочная кривая построена (20+ точек)

### Phase 3 ✓ PRODUCTION
- [ ] DBF алгоритм работает в реальном времени
- [ ] Дальность 150+ метров с DBF
- [ ] EMC сертификация пройдена
- [ ] Система готова к масштабированию (16+ элементов)
- [ ] Готово к совместной разработке на производстве
