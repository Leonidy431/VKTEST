# ТЗ: корпус и разъемы под выбранные стандартные платы (12 фаз)

Техническое задание на проектирование несущей платы (KiCad), корпуса и
панельных разъемов портативного аппарата электромуфтовой сварки под уже
выбранные стандартные покупные платы/модули (см. `hardware/platforms.md`,
`hardware/bom.csv`):

| Модуль | Выбранная плата | Что нужно на несущей плате |
|---|---|---|
| Вычислитель | ESP32-S3-DevKitC-1 | Розетка 2×(1×22) 2.54мм |
| Дисплей | TFT 2.4" SPI 280×320 | Разъем 1×14 + окно в корпусе |
| Датчик тока | ACS758LCB-150B модуль | Разъем 1×3 |
| RTC | DS3231 модуль | Разъем 1×4 (I2C) |
| microSD | SPI microSD модуль | Разъем 1×6 |
| Температура | DS18B20 ×3 (1-Wire шина) | Разъем 1×3 |
| Zero-Cross | Модуль компаратора LM393 | Разъем 1×3 |
| Драйвер симистора | Модуль MOC3083 | Разъем 1×3 |
| Кулер | 48мм 5В PWM | Разъем 1×3 |
| Батарея 48В | XT90PW-M (PCB-монтаж) | Силовое посадочное место |
| Сварочный выход | Клеммы M4 | Болтовые площадки Ø10/4.3 |
| Сканер штрих-кода | USB-карандаш | Панельный USB-A (без платы) |

**Важно о зоне ответственности KiCad**: сам пластиковый корпус (IP54)
проектируется в CAD (FreeCAD, фазы 8-9) — KiCad отвечает за несущую
плату, ее контур, крепеж, разъемы и экспорт STEP для сборки с корпусом.

**Статус**: фаза 3 начата — скелет проекта создан в
`hardware/electronics/carrier/` (контур, крепеж, черновые посадочные
места). Все размеры с пометкой «проверить» блокируют переход к фазе 6.

---

## Фаза 1. Верификация габаритов выбранных плат

- Свести в таблицу точные габариты, шаг и разводку выводов каждой платы
  из таблицы выше — по даташитам производителей, не по памяти
  (методология критика: `hardware/platforms.md` уже содержит поля
  «не подтверждено» — они закрываются здесь).
- Ключевой неподтвержденный размер: межрядное расстояние гребенок
  ESP32-S3-DevKitC-1 (принято 22.86мм / 0.9", требует проверки по
  чертежу Espressif).
- **Выход**: `hardware/electronics/carrier/dimensions.md` без единого
  поля «не подтверждено».
- **Критерий приемки**: каждый размер имеет ссылку на источник
  (даташит/чертеж производителя).

## Фаза 2. Библиотека посадочных мест KiCad

- Собственная библиотека footprint'ов: XT90PW-M, клеммы M4, держатель
  предохранителя 5×20, гребенки 1×N, крепежные отверстия M3.
- У каждого посадочного места: courtyard, Fab-контур, 3D-модель
  (шаг/STEP), проверка по даташиту из фазы 1.
- **Критерий**: библиотека проходит KiCad Footprint Checker без ошибок.

## Фаза 3. Контур несущей платы и крепеж *(начата)*

- Контур 160×110мм (2 слоя, 1.6мм, медь 2oz для силовых цепей —
  уточняется в фазе 5), 4 отверстия M3 с зенковкой под бобышки корпуса.
- Черновая расстановка всех разъемов из таблицы (сделано в скелете).
- **Критерий**: плата открывается в KiCad ≥7 без ошибок формата,
  Edge.Cuts замкнут, крепеж совпадает с бобышками корпуса (фаза 8).

## Фаза 4. Схема: подключение разъемов к DevKitC-1

- Полная схема соединений разъем → GPIO с явной таблицей пинов.
- Константы GPIO синхронизировать с прошивкой (`firmware/main/*.h`:
  ZC_GPIO=4, TRIAC_GATE=5, АЦП каналы 0/1) — единый источник истины,
  расхождение схема/прошивка = блокер.
- **Критерий**: ERC без ошибок; таблица пинов в схеме и в
  `firmware/README.md` идентичны.

## Фаза 5. Зонирование, зазоры и токовые сечения

- Три зоны: слаботочная (3.3/5В), силовая 48В, сварочный выход (до
  110А рабочих / 120А отсечка).
- Расчет ширины/толщины проводников и полигонов на 110А (IPC-2152),
  при необходимости — медные шины поверх платы.
- Зазоры/creepage по IPC-2221 для 48В зоны; сетевых 220В цепей на
  несущей плате НЕТ (инвертор и трансформатор — отдельные покупные
  блоки, соединение кабелями).
- **Критерий**: расчетный нагрев силовых дорожек < 20°C при 110А.

## Фаза 6. Трассировка и DRC

- Полная разводка, полигоны земли, термобарьеры на силовых пятаках.
- **Критерий**: DRC без ошибок; отчет приложен в
  `hardware/electronics/carrier/reports/`.

## Фаза 7. Ревью платы против FMEA

- Каждая строка `docs/safety_analysis.md` проверяется на плате:
  предохранитель до XT90 (#3), сечение сварочного выхода (#1-2),
  развязка драйвера симистора (#2), датчик тока в разрыве нужной цепи.
- **Критерий**: таблица соответствия «риск FMEA → решение на плате»
  без открытых пунктов.

## Фаза 8. Корпус: 3D-сборка

- FreeCAD: корпус ~200×150×100 IP54 (ABS+PC, `hardware/bom.csv`),
  бобышки под несущую плату (совпадают с фазой 3), батарейный отсек
  48В с фиксацией, площадка радиатора 500см².
- Импорт STEP платы из KiCad — проверка коллизий.
- **Выход**: `hardware/mechanical/enclosure.FCStd` + STEP.
- **Критерий**: нет пересечений компонентов, зазор ≥3мм до стенок.

## Фаза 9. Панели, вырезы и герметизация

- Вырезы: окно TFT (+поликарбонат 3мм), 4 мембранные кнопки IP65,
  панельный USB-A (сканер), гермовводы сварочных кабелей 10мм²,
  ниша XT90-S, решетки вентиляции с лабиринтом от брызг.
- Прокладки/уплотнения для каждого выреза — это ответ на риск #11
  FMEA (RPN=30, наивысший в проекте).
- **Критерий**: перечень всех отверстий с типом уплотнения; концепция
  подтверждает класс IP54.

## Фаза 10. Термопроект

- Радиатор симистора 500см² + кулер 48мм: воздуховод внутри корпуса,
  вход/выход воздуха через лабиринты фазы 9.
- Оценка: ~42Вт рассеивания при полной мощности; целевая T радиатора
  <70°C при +40°C снаружи (порог derating из `SafetyLimits`).
- **Критерий**: расчет/симуляция приложены; пороги согласованы с
  `control/safety_validator.py` (70/80°C).

## Фаза 11. Прототип

- Гербер + BOM + позиционные файлы из KiCad; заказ платы (2oz медь).
- 3D-печать корпуса (PETG/ASA для прототипа), закупка разъемов по
  `hardware/bom.csv`.
- **Выход**: комплект производственных файлов в
  `hardware/electronics/carrier/fab/`.
- **Критерий**: файлы проходят DFM-проверку изготовителя.

## Фаза 12. Верификация прототипа

- Fit-check всех плат и разъемов; момент затяжки M4 клемм.
- Душ-тест IP54 (закрывает риск #11 FMEA), вибротест переноски.
- Прогон `docs/commissioning.md` §1-2 (входной контроль, калибровка)
  на собранном изделии.
- **Критерий**: обновлены `hardware/bom.csv`, `docs/safety_analysis.md`
  (O/D-оценки по фактам), `docs/commissioning.md`; расхождения
  чертеж/реальность задокументированы и исправлены.

        └────→ 8 → 9 → 10 ─┴→ 11 → 12
