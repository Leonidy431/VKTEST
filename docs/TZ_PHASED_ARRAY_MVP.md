## 1. Цель и границы

### Цель
Создать модуль беспроводной связи высокоскоростной robот-phone (`robot ↔ phone`) на базе
готовых компонентов с поддержкой адаптивного формирования луча (beamforming) для:
- Передачи видеопотока (720p@30fps, ~3-5 Мбит/с)
- Управления роботом в реальном времени
- Расширенного диапазона связи (50-100 м в открытом пространстве)

### Не входит в MVP
- ❌ Проектирование собственной ФАР платы (KiCad)
- ❌ FPGA управление фазовращателями
- ❌ Адаптивное цифровое формирование луча (только встроенное в чип)
- ❌ Поддержка частот <2.4 ГГц или >6 ГГц

## 4. Фазы реализации (roadmap)

### Фаза 1: MVP (Недели 1-3)
```python
Этап 1.1: Закупка готовых модулей
├─ Qorvo QPM56xx series evaluation board или Wi-Fi 7 роутер
├─ LMR-100 кабели, IPEX/SMA разъемы
├─ Оценочная плата FPGA для управления мощностью
└─ Расчет → заказ → доставка

Этап 1.2: Механический монтаж
├─ Демонтаж антенн от поставляемого модуля
├─ Пайка кабелей на разъемы
├─ Крепеж на корпусе робота (алюминиевые уголки)
└─ Испытание механической жесткости

Этап 1.3: Программное обеспечение управления
├─ Python API для RF модуля (SPI/I2C инициализация)
├─ Контроль питания PA/LNA (on/off, мощность)
├─ Логирование RSSI (Received Signal Strength Indicator)
└─ Интеграция с mainloop робота

Этап 1.4: Тестирование (базовое)
├─ Диаграмма направленности (pattern) вручную
├─ Измерение дальности связи
├─ Проверка стабильности соединения
└─ Проверка тепловыделения
```

**Результат:** Рабочий стенд `robot ↔ phone` на готовых модулях.

### Интеграция с управлением роботом

```python
# robot_controller.py (псевдокод)

from phased_array import RFModule, BeamForming
from control import MainController

class EnhancedRobotController(MainController):
    def __init__(self):
        super().__init__()
        self.rf_module = RFModule(
            chip='Qorvo_QPM56xx',
            frequency=5.8e9,  # 5.8 ГГц
            tx_power=20  # дБм
        )
        self.beamforming = BeamForming(
            num_elements=4,
            element_spacing=0.5  # в длинах волн λ
        )
    
    def control_loop(self, dt):
        """Основной цикл управления."""
        # Существующая логика робота
        super().control_loop(dt)
        
        # RF компонент: адаптивная мощность
        rssi = self.rf_module.get_rssi()  # Сила сигнала
        if rssi < -80:  # Слабый сигнал
            self.rf_module.set_tx_power(22)  # Повысить мощность
            self.beamforming.scan_for_max_gain()  # Поиск оптимального луча
```

## 7. Критерии приемки MVP

### Функциональные

- [ ] Модуль инициализируется и подключается к RF чипсету
- [ ] Беспроводная связь `robot ↔ phone` устанавливается без ошибок
- [ ] Видеопоток 720p передается со скоростью ≥20 fps
- [ ] Управление роботом по Wi-Fi работает с задержкой <100 мс
- [ ] Мощность TX может быть регулируемой в диапазоне ±6 дБм

### Тестирование

- [ ] Все 10+ тестов проходят успешно (`pytest phased_array/tests/`)
- [ ] RSSI логируется корректно (значение -20…-100 дБм)
- [ ] Нет коррупции данных при transmit на максимальной мощности
- [ ] Тепловыделение не превышает 8 °C над окружающей средой

### Документация

- [ ] README с инструкциями по сборке и запуску
- [ ] Datasheet модуля на русском и английском
- [ ] Диаграмма направленности (паттерн антенны) в декартовых координатах
- [ ] Чек-лист интеграции с текущим контроллером робота

### Безопасность

- [ ] Нет утечек RF в цифровые линии управления (ЭМС)
- [ ] Переполнение буфера TX не вызывает зависание контроллера
- [ ] Отключение питания RF не вызывает сбой mainloop

## 8. Критические точки и риски

| Риск | Вероятность | Влияние | Смягчение |
|------|-------------|--------|----------|
| Чипсет недоступен на рынке | Низкая | Высокое | Запас компонентов (+2 шт) |
| RF кабель вызывает помехи | Средняя | Высокое | Экранирование + тесты |
| Тепловыделение превышает норму | Средняя | Среднее | Пассивный радиатор на PA |

| Задержка (latency) превышает 100 мс | Низкая | Среднее | Профилирование + оптимизация IQ-буфера |

## 9. Методология отладки RF (для фаз 2-3)

При возникновении проблем с качеством связи используйте систематический подход:

```
1. Визуальная инспекция
   ├─ Целостность пайки (микроскоп ≥20x)
   ├─ Отсутствие трещин в печатных линиях
   └─ Плотность контактов разъемов

2. Электрический тест
   ├─ DC сопротивление кабеля (должно быть <0.5 Ом/м)
   ├─ Изоляция кабеля (мегаомметр, >100 МОм)
   ├─ Impedance match на разъемах (50 Ом ±2 Ом)
   └─ Непрерывность шин питания (нет >0.1 В падения)

3. RF тест (требует оборудования)
   ├─ S-параметры кабеля (VNA или сетевой анализатор)
   ├─ Диаграмма направленности антенны (анихотическая камера)
   ├─ Спектр излучения (спектроанализатор, диапазон ±100 МГц)
   └─ Шумовая фигура системы (Noise Figure <6 дБ для 5 ГГц)

4. Программный тест
   ├─ Логирование RSSI на различных расстояниях
   ├─ Проверка скорости TX/RX (throughput test)
   ├─ Тест на потерю пакетов (packet loss <1%)
   └─ Профилирование CPU/памяти контроллера
```

## Приложение: Глоссарий терминов

| Термин | Определение |
|--------|----------|
| **AESA** | Active Electronically Scanned Array — активная фазированная антенная решетка |
| **Beamforming** | Формирование луча за счет управления фазой сигнала на элементах |
| **RSSI** | Received Signal Strength Indicator — индикатор мощности полученного сигнала (дБм) |
| **Phase Shifter** | Компонент, изменяющий фазу сигнала на величину 0…360° |
| **Impedance Match** | Согласование импеданса (50 Ом) между компонентами RF тракта |
| **Latency** | Задержка передачи пакета от TX до RX (в миллисекундах) |
| **SNR** | Signal-to-Noise Ratio — отношение мощности сигнала к шуму (в дБ) |
