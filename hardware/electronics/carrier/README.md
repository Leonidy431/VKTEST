# Несущая плата (carrier) — KiCad

Скелет проекта несущей платы под выбранные стандартные модули
(ESP32-S3-DevKitC-1, TFT SPI, ACS758, DS3231, microSD и др.) —
фаза 3 ТЗ `docs/enclosure_tz.md`.

## Файлы

- `carrier.kicad_pro` / `carrier.kicad_sch` / `carrier.kicad_pcb` —
  проект KiCad ≥7. Плата: 160×110мм, крепеж M3×4, 20 посадочных мест,
  102 площадки.
- `generate_kicad.py` — генератор этих файлов (единственный источник
  истины на фазе 3). Запуск: `python3 generate_kicad.py` из этого
  каталога; вывод детерминирован (uuid5), diff чистый.

## Статус и ограничения

- Посадочные места — **черновые** (расстановка и состав), не
  библиотечного качества: без courtyard/3D-моделей (фаза 2 ТЗ).
- Размеры с пометкой `verify` в `generate_kicad.py` (межряд DevKitC-1
  22.86мм, шаг XT90PW 10.5мм, шаг клипс предохранителя 22мм) требуют
  сверки с даташитами (фаза 1) до трассировки.
- Схема содержит только карту разъемов текстом; символы и ERC — фаза 4.
- KiCad недоступен в среде разработки — файлы проверены на
  синтаксическую сбалансированность генератором; открытие в KiCad —
  первый шаг фазы 6.

После ручного редактирования платы в KiCad генератор следует либо
удалить, либо обновлять синхронно — двух источников истины быть
не должно.
