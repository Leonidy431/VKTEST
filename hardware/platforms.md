# Выбор платформы: ESP32 dev-board для контроллера сварки

## Требования проекта к GPIO-бюджету

Прежде чем сравнивать платы, зафиксируем минимальный бюджет выводов, который
требует наша архитектура (см. `docs/architecture.md`):

| Функция | Выводов |
|---|---|
| Управление симистором (ШИМ/импульс через оптрон MOC3083) | 1 |
| Zero-Cross Detector (прерывание) | 1 |
| АЦП: напряжение вторичной обмотки | 1 |
| АЦП: ток (датчик Холла ACS758) | 1 |
| DS18B20 (радиатор, окруж. среда) — 1-Wire, можно на одной шине | 1 |
| I2C (RTC + опционально IO-расширитель) | 2 |
| SPI TFT дисплей (CS, DC, RST, SCK, MOSI) | 5 |
| SD карта (может делить SPI шину с дисплеем) | 1 (CS) |
| USB сканер штрих-кода (UART или нативный USB) | 2 (UART) или 0 (native USB) |
| Кнопки (START/STOP, MENU UP/DOWN) | 4 |
| Зуммер | 1 |
| BMS/батарея мониторинг (аналог/I2C) | 1-2 |

**Итого: минимум ~20-22 GPIO** для комфортной разводки без внешнего
I2C-расширителя портов. Платы с <20 GPIO (XIAO ESP32S3 — 11 пинов,
M5StickC PLUS2) отсеиваются сразу — критик отмечает, что их использование
потребует I2C GPIO-экспандер, который вносит недопустимую задержку в
времязадержку открытия симистора (нужна микросекундная точность,
несовместимая с опросом по I2C).

По той же причине **M5Stack CoreS3** (GPIO только через AW9523B expander)
исключен из роли основного MCU силовой части — он может использоваться
только как отдельный HMI-модуль, если решим разделить силовую логику и
интерфейс на два контроллера.

## 12 параметров отбора

1. Ядро/чипсет
2. Тактовая частота
3. ОЗУ (SRAM/PSRAM)
4. Флэш-память
5. АЦП (каналы, разрядность)
6. Свободные GPIO
7. Беспроводная связь (Wi-Fi/BLE)
8. Ток потребления (актив/сон)
9. Диапазон рабочих температур
10. Форм-фактор/габариты
11. Открытость схем (Open Hardware)
12. Цена (USD)

прототипа, и как референс для финальной кастомной платы.

|---|---|
| Прототипирование / симуляция логики | **ESP32-S3-DevKitC-1** |

| Серийное производство, минимизация цены | **Generic N16R8 клон** — только после входного контроля партии |

## Отклоненные кандидаты (и почему)

- **Seeed XIAO ESP32S3** — 11 GPIO, недостаточно для проекта без I2C-экспандера (задержка триггера симистора).
- **M5StickC PLUS2** — базовый ESP32 (не S3), GPIO не найден в открытых источниках, форм-фактор избыточно миниатюрный для промышленного корпуса.
- **M5Stack CoreS3** — GPIO только через I2C IO-expander (AW9523B), несовместимо с микросекундным управлением симистором; допустим только как отдельный HMI-модуль.
- **ESP32-WROVER-E** — устаревший BLE 4.2 (vs 5.0 у S3), меньше GPIO (24 vs 45), нет прироста в цене относительно WROOM-1.
