# Project Structure

Актуальная структура репозитория (см. также `docs/architecture.md` за
подробным описанием потока данных).

- **README.md** — методология "Скептичный критик" + обзор реализации
- **CLAUDE.md** — инструкции для Claude Code сессий, работающих в этом репозитории
- **simulation/** — физическая модель (Python): закон Джоуля-Ленца, ПИД-регулятор, батарея/сеть
- **control/** — управляющая логика: конечный автомат, оркестратор, защиты
- **critical_analysis/** — методология критика как код:
  - error_detector.py
  - physics_validator.py
  - standards_checker.py
  - solution_synthesizer.py
- **protocol/** — формат штрих-кода муфты, криптографическая прослеживаемость
- **firmware/** — C-порт для ESP32-S3 (esp-idf)
- **hardware/** — выбор платы, BOM, схемы
- **docs/** — архитектура, трассируемость 99 фактов, энергетический бюджет,
  FMEA безопасности, процесс ввода в эксплуатацию, журнал решений сессии
- **tests/** — 70+ тестов (pytest)
